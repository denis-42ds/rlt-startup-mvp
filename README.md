# RLT.Startup

MVP B2B-маркетплейса для взаимодействия покупателей и поставщиков с поддержкой ИИ-агентов.

## Технологии

- Python
- FastAPI
- PostgreSQL
- Локальная LLM через Ollama

## Разработка

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Установка проекта в editable-режиме:

```bash
python -m pip install -e .
```
